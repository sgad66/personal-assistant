# AI 日程助手

一个本地优先的 AI 日程桌面应用：用一句话、一段语音或一张截图录入事项，自动解析时间、地点和备注；也会记住你的偏好，按节奏跟进目标，在早上、晚上和周末把回顾直接写进对话。

应用基于 Electron + React + TypeScript 构建，数据默认保存在本机，不依赖云端账户。

## 功能

- **多模态录入**：文字、语音、图片通知截图
- **对话式安排**：补全缺失信息、候选事项勾选、时间冲突确认；单条消息可经二次确认后删除
- **目标与定时跟进**：AI 可在对话中自主建立每天 / 工作日 / 每周 / 间隔 / 一次性的跟进目标，到点自动检查进度、写回对话并给出下一步
- **长期记忆**：对话中明确说出的偏好、习惯、个人信息和承诺会被自动学习、去重与分类；提问时按相关性注入，而不是把所有记忆一次性塞进上下文
- **长上下文**：较早的对话滚动生成摘要，结合最近消息、相关记忆、目标和未来日程一起送入模型，长对话不丢早期信息
- **日常回顾与提醒**：早上给出今日计划、晚上做回顾、周末回看节奏，自然写进对话；关注生日 / 纪念日、重要事项准备、停滞目标和今晚的复盘问题；22:30–08:00 静默，每天最多 3 条
- **周日程**：时间轴 / 列表 / 概览三种视图
- **近期焦点词云**：首页汇总本周安排、进行中的目标、近期记忆与对话里的高频短语，生成一张无边框的云状词云；词语围绕中心自然排布、互不重叠，点击任一焦点词即可和助理接着聊
- **冲突分组卡**：重叠事项合并展示，逐条可打开详情，不遮挡、不挤压
- **DIY 看板**：今日节奏、今日安排、本周概览、空档建议、模板、打卡、专注计时等组件，可增删、拖动排序、调整宽窄
- **布局预设**：日常 / 工作 / 生活 / 极简
- **提醒**：事项开始前 10 分钟提醒，支持稍后提醒与忽略
- **托盘常驻**：可设置关闭窗口时最小化到系统托盘
- **小窗模式**：右下角悬浮小窗，显示下一项安排，一键恢复主窗口
- **AI 服务配置**：文本、视觉、语音可分别接入不同服务商；默认文本使用本地规则解析
- **设置**：偏好、长期记忆、目标入口、连接与密钥集中管理；记忆会在提问时按相关性进入上下文
- **本地优先**：日程数据保存在本机，API Key 使用 Electron safeStorage 加密

## 快速开始

```bash
npm install
npm run dev
```

如果终端环境预设了 `ELECTRON_RUN_AS_NODE=1`，Electron 会以纯 Node 模式启动并报错。启动桌面窗口前需要清除该变量：

```bash
unset ELECTRON_RUN_AS_NODE
npm run dev
```

## 一键启动（推荐）

装好 Node.js 22+ 后，双击桌面上的「**AI 日程助手**」快捷方式即可启动，不需要打开终端。

快捷方式指向工程根目录的 `启动个人助理.bat`，它调用 `scripts/launcher/launch.cjs`，启动前会自动完成：

1. **环境检测**：操作系统、Node.js、npm、项目依赖、Electron 运行文件、构建产物、开发端口
2. **自动修复**：依赖缺失时自动 `npm install`；Electron 运行文件缺失时自动修复；构建产物缺失时自动 `npm run build`
3. **自动选模式**：构建产物完整走生产模式（秒开），否则走开发模式（带热更新）
4. **防重复启动**：已在运行时不再开第二个实例，改为唤起已有窗口
5. **失败可读**：出错时给出错误码、原因、建议和日志路径

五个入口脚本：

| 文件 | 用途 |
| --- | --- |
| `启动个人助理.bat` | 自动选模式（日常用这个） |
| `生产模式启动.bat` | 强制走生产模式，构建产物不完整时会先构建 |
| `开发模式启动.bat` | 强制走开发模式，改代码即时生效 |
| `检查运行环境.bat` | 只做环境自检并给出结论，不启动 |
| `桌面快捷方式.bat` | 创建 / 删除 / 查看桌面快捷方式 |

启动器产生的文件（已被 `.gitignore` 忽略）：

- `.launcher/logs/launch-YYYYMMDD.log`：结构化启动日志，默认保留 30 天 / 20 个文件
- `.launcher/state/launch-state.json`：运行状态，用于防重复启动

可在工程根目录新建 `launcher.config.json` 覆盖默认配置，例如：

```json
{
  "defaultMode": "auto",
  "portRange": 5173,
  "shortcutName": "AI 日程助手",
  "launchTimeoutSec": 180
}
```

## 使用方式

### 今日

轻量入口：问候、今日概览、快捷录入，以及一张近期焦点词云。输入一句“明天下午三点开项目周会”直接回车，会自动进入对话页展示解析结果。

焦点词云只读取本机数据，从本周日程标题、进行中的目标、近 14 天的记忆与对话中提取高频短语，按出现次数与来源权重排布成围绕中心的椭圆云团；大词居中、小词向外散开，颜色按名次固定，不会每次打开都变化。点击一个焦点词会带着这句话进入对话，直接继续追问。

### 对话

查看完整对话、附件、候选事项、冲突决策与会话历史。支持补充信息、重新描述、重试上一条；每条提问或回答都可以单独删除，删除前会二次确认，删除后旧摘要与未完成的待确认状态会同步失效。

### 目标

让助理替你记住需要持续推进的事：

- **自动建立**：在对话里说“每天 21:00 提醒我复盘”“每周五跟进项目进度”“每隔 2 小时检查论文”，助理会建立目标，并在回复里附上“目标跟进”入口
- **定时汇报**：到达设定节奏后，主进程定时器会触发一次检查。接入 AI 时由模型根据目标、上次进度和最近记录生成汇报；本地模式下只做温和回访，不虚构进度
- **进度写回**：每次检查会记录进度百分比、摘要和下一步，并自动追加一条对话消息；应用不在前台时会发系统通知
- **手动管理**：目标页可立即跟进、暂停、继续、标记完成、删除，并展开查看历史检查记录
- **不重复创建**：AI 对同名目标会复用已有记录；一次性日程不会被误判为目标

### 看板

工作与生活组件的自由组合：

- 编辑模式支持拖动排序、宽/窄切换、隐藏、组件库添加
- 预设：日常 / 工作 / 生活 / 极简
- 布局保存在本机

### 本周

右上角可切换：

- **时间轴**：按小时查看时间分布与冲突
- **列表**：按天扫读
- **概览**：每天一张摘要卡

重叠事项会合并成一张“时间重叠 · N 项”的冲突分组卡，逐条点击进入详情。

### 设置

侧栏进入「设置」：

- **偏好**：深色模式、关闭窗口时最小化到托盘
- **长期记忆**：自动学习与手动添加、置顶、删除、清空
- **目标与定时跟进**：进入目标页管理进度
- **数据与隐私**：查看本地存储与联网说明

顶部的「连接设置」打开文本 / 视觉 / 语音连接配置与 API Key 管理。

### 记忆与日常回顾

设置页中的「长期记忆」与内置回顾：

- **长期记忆**：手动添加偏好 / 个人信息 / 习惯 / 事实 / 关系 / 承诺；对话中明确表达时也会自动学习。记忆会去重、按相关性检索，并显示“自动学习 / 模型学习 / 已迁移 / 手动添加”来源
- **旧记忆迁移**：早期保存在本机的记忆会在首次启动时自动迁移到主进程数据库，迁移完成后不再通过前端存储注入
- **滚动摘要**：对话超过 6 条新消息后，后台生成或合并摘要；后续提问会同时携带摘要、最近对话、相关记忆、目标和未来 36 小时日程
- **日常回顾**：08:30 给出今日计划、21:30 做晚间回顾、周日 20:30 回看一周；直接写进对话，不需要额外设置
- **运行方式**：回顾由主进程定时触发，应用保持运行即可（可缩到托盘）；完全退出应用后不会补发
- **克制打扰**：22:30–08:00 静默，每天最多 3 条；周日每周回顾会替代当晚的晚间回顾
- **关注细节**：今日计划会识别记忆中的生日 / 纪念日；晚间回顾会提醒明天的重要事项准备，并指出连续没有进展的目标
- **离线降级**：本地模式仍会按时生成基于日程和目标的回顾，不虚构完成情况；接入文本模型后由模型生成更自然的回顾

### 托盘与小窗

- 关闭窗口（默认）→ 隐藏到系统托盘
- 托盘菜单：打开主窗口 / 小窗模式 / 退出

- 侧栏“小窗模式”可直接打开

## AI 配置说明

- 默认 `text` 通道使用本地规则解析，不需要 API Key
- 语音与图片识别需要在设置中接入支持的服务商
- 文本、视觉、语音可分别绑定不同服务商
- Key 会优先使用 Electron safeStorage 加密保存；降级时仅写入本机用户数据目录
- 语音/图片临时文件仅用于解析，解析后会清理

### 免费方案推荐

三个通道都可以零成本跑起来，下面两套组合任选其一。

**方案一：国内直连（推荐，无需代理）**

| 通道 | 服务商 | 端点 | 模型 | 免费说明 |
| --- | --- | --- | --- | --- |
| 图片识别 | 智谱 GLM | `https://open.bigmodel.cn/api/paas/v4` | `glm-4.6v-flash` | 该模型输入输出均免费，按速率限制 |
| 语音识别 | 硅基流动 | `https://api.siliconflow.cn/v1` | `FunAudioLLM/SenseVoiceSmall` | 该模型免费，按速率限制 |

配置步骤：设置 → AI 服务，图片通道选「智谱 GLM（国内直连）」，模型填 `glm-4.6v-flash`；语音通道选「自定义（OpenAI 兼容）」，端点填 `https://api.siliconflow.cn/v1`，模型填 `FunAudioLLM/SenseVoiceSmall`。两个 Key 分别到 bigmodel.cn 与 siliconflow.cn 注册获取，均无需付费。

**方案二：一个 Key 三通道全包（Groq，可直连）**

| 通道 | 模型 | 免费额度（Free 计划） |
| --- | --- | --- |
| 文本 | `openai/gpt-oss-120b` | 30 RPM / 1000 次每天 / 8K tokens 每分钟 |
| 图片识别 | `qwen/qwen3.8-27b` | 同上（预览模型，支持图片输入） |
| 语音识别 | `whisper-large-v3-turbo` | 20 RPM / 2000 次每天 / 每天 28800 秒音频 |

在设置里选「Groq（免费推荐）」，一个 Key 同时启用三个通道即可。注意该模型为 Preview 版本，可能随时调整；额度与模型可用性以服务商政策为准。

> 模型和服务商政策会变化。2026-11 核对时：Groq Free 计划已不含 `llama-3.3-70b`（转企业版）、`llama-4-scout` 也已下线，故本项目预设默认值已同步为上述新模型。

## 数据与隐私

- 日程数据保存在 Electron 的 `userData` 目录
- 长期记忆、对话摘要、回顾运行状态同样保存在本机数据库
- 语音、图片只在解析时使用
- 自动学习记忆与生成对话摘要只在配置了文本模型时调用模型；本地模式下使用规则提取和本地摘要
- 记忆内容会作为参考上下文发送给已配置的文本模型，但不会被当作可执行指令
- 不配置 AI 服务时，除本地规则解析外不会联网
- 应用不包含账号体系，不会上传日程到自建服务器

